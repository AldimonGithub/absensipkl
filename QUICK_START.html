📚 Panduan Cepat Sistem Absensi QR Code

🚀 Quick Start (5 Menit)

1. Persiapan Database

Import file config/schema.sql ke MySQL:

mysql -u root -p absensi_qrcode < config/schema.sql

2. Konfigurasi Database

Edit config/database.php:

define('DB_HOST', 'localhost'); define('DB_USER', 'root'); define('DB_PASS', ''); define('DB_NAME', 'absensi_qrcode');

3. Setup Folder Permission

chmod 755 uploads/

4. Akses Aplikasi

Buka di browser: http://localhost/Absensi/

✓ Aplikasi sudah siap digunakan!

🔄 Alur Penggunaan Sistem

Untuk Siswa:

  1. Login → Masukkan Nomor HP & Password
    URL: http://localhost/Absensi/
  2. Verifikasi CAPTCHA → Masukkan kode CAPTCHA
    URL: /pages/verif-user.php
  3. Scan QR Code → Arahkan kamera ke QR
    Gunakan QR: SISWA-001-QRCODE atau SISWA-002-QRCODE
  4. Absensi Masuk → Pilih status & isi keterangan (jika perlu)
    Status: Hadir (hijau), Sakit (merah), Izin (kuning), Absen (merah)
  5. Absensi Pulang → Setelah pukul 12:00, konfirmasi keluar
    Status: Pulang Cepat, Tepat Waktu, Lembur

Untuk Admin:

  1. Login Admin → Masukkan Username & Password
    URL: /pages/login-admin.php
  2. Dashboard → Lihat semua data absensi
    URL: /pages/admin-interface.php
  3. Filter & Cari → Gunakan filter untuk menemukan data spesifik

⚡ Catatan Penting

Waktu Operasional:

  • Absensi Masuk: Mulai pukul 06:00
  • Batas Tepat Waktu: 08:00
  • Batas Toleransi: 08:30
  • Absensi Pulang: Mulai pukul 12:00

Fitur QR Code:

  • Browser harus support WebRTC (Chrome, Firefox, Safari, Edge)
  • Izinkan akses kamera di browser settings
  • Gunakan HTTPS atau localhost

Upload Bukti File:

  • Format: JPG, JPEG, PNG, MP4, AVI
  • Maksimal: 10MB
  • Hanya untuk status Sakit/Izin/Absen

Password & Security:

  • Semua password di-hash dengan bcrypt
  • Jangan bagikan password default
  • Change password secara berkala

💾 Perintah Berguna

Backup Database:

mysqldump -u root -p absensi_qrcode > backup_$(date +%Y%m%d).sql

Restore Database:

mysql -u root -p absensi_qrcode < backup_20260412.sql

Reset Password Siswa:

UPDATE siswa SET password = '$2y$10$YOUR_HASHED_PASSWORD' WHERE nomor_hp = '08123456789';

Generate Password Hash:

php -r "echo password_hash('password123', PASSWORD_BCRYPT);"

Clear Upload Files (30+ hari):

find uploads/ -type f -mtime +30 -delete
